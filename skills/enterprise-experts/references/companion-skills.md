# Companion Skills & Plugins (Sara's catalogue)

These are the specialist skills/plugins Sara mapped to each expert. They are optional boosters, not requirements: every expert can do its job with the built-in checklists in this skill.

How to use this list:
- If a companion skill or plugin is **already available in this session** (check the available skills list / connected tools), use it for that expert's deep work and say so in the deliverable.
- If it isn't installed, don't stop: use the built-in checks, and list the companion in the report's "Recommended tooling" section when it would have unlocked better evidence.
- Community skills vary in quality. Before recommending installation, remind the user to inspect the source and permissions. Never install anything without the user's approval.

The shared-foundation ideas are already built into this skill's workflow: question requirements before building (grill-me), plan before changing (writing-plans), investigate before fixing (systematic-debugging), tests guide changes (test-driven-development), and evidence before claiming completion (verification-before-completion).
